# V2.6 历史估值数据采集与审计规范

## 研究问题
在**同一股票、相近恐慌分数**的独立事件中，保守内在价值与价格之差是否与未来5/10/20/60交易日收益分布、沪深300超额收益及收盘价口径最大不利波动相关？

**禁止**：用当前财报回填过去、把历史高价或均价当内在价值、对缺失数据填零、把本研究的“个股VIX”解释为期权隐含波动率。

## 输入文件
`v2/valuation/point_in_time_valuations.csv`：
`code,asof_date,available_date,conservative_value,method,source`

- `code`：六位证券代码，保留前导零。
- `asof_date`：财务报告截止日期（YYYY-MM-DD）。
- `available_date`：估值依据的全部资料**最后一项公开发布**的日期，必须晚于或等于 `asof_date`；不可用未来披露的信息。
- `conservative_value`：在当时股本和分红/复权一致口径下，按保守假设计算的**每股人民币内在价值**；必须大于零。
- `method`：估值方法与版本，例如 `FCF_DCF_v1`、`normalized_earnings_v1`。
- `source`：原始公告/财报链接、发布日期、估值假设工作底稿位置；须可复核。

每一行是一份当时可用的估值快照，非今日追溯主观判断。尚未采集到可靠资料时，保持表格为空。

## 检验与质量门槛
1. 先验证历史数据来源、发布时间、估值假设可复核，再计算安全边际。
2. 不把日度样本数当独立事件数；事件按阈值首次突破并设置20交易日冷却期。
3. 按恐慌阈值、估值安全边际分层，报告P10/P25/P50/P75/P90和样本量；小样本只作探索性结果。
4. 未来20/60日价格路径的最大不利波动必须报告，并提示仅收盘价口径，未计交易费用和涨跌停成交约束。
5. 对照组需要同股票、相近时间/市场环境、相近恐慌水平，且必须检查各组样本量与可比性；仅做分组描述不能宣称因果。
6. 只有估值快照可追溯且样本覆盖充足，才能讨论估值安全边际的预测效果。没有数据则输出 `awaiting_historical_valuations`。
