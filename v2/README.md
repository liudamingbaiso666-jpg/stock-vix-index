# V2.0 第一阶段：多指数候选股票池

目标：沪深300（000300）＋中证A50（930050）＋中证500（000905），以六位A股代码合并去重。

## 运行
在仓库根目录安装已有 requirements.txt 的依赖后：

```bash
python v2/build_universe.py
```

成功后生成 `v2/data/universe_YYYY-MM-DD.csv` 和同名 JSON，记录成分股来源、拉取时间、指数归属、待审核状态。该脚本目前**尚未通过 GitHub Actions 实测**，指数接口及字段可能随 AkShare 版本变化；若接口失败或成分数量异常，脚本会报错，不能把结果视为已验证。

## 研究边界
- 指数成分股是**候选母池**，不是优质企业认证，也不是买入名单。
- 企业质量和估值状态初始均为 `pending`。
- V1.0 文件和工作流不变。
- 每次更新保存带日期的快照；同一天重复运行会覆盖当日快照。
- 历史回测必须使用历史时点成分股，不得把今天的名单当作过去的名单。
- 下一步：验证数据源、首次运行并检查三个指数数量及合并结果，然后决定是否增加自动运行工作流。
